# 私人自用的飞书记账 Skill

这是我给自己使用的 `feishu-bookkeeping` Skill。它让 Codex 等本地智能体根据我的消费分类习惯，通过受限工具向我的飞书多维表格新增消费记录。

**这个仓库用于保留个人项目的实现记录，不提供可供他人直接使用的记账产品。** 实际运行所需的个人知识库、账本配置、飞书授权和运行数据均未上传。克隆仓库不能直接连接账本或开始记账；源码中的分类示例、接口和测试结果也不代表适合其他人的记账习惯。

## 为什么做这个项目

我先开发了一个自主决策记账智能体，由模型理解自然语言消费、判断个人分类，并通过受限工具操作飞书账本。这个项目沿用它的业务规则与工具边界，把模型调用和 Agent 运行循环交给 Codex 等宿主，保留个人知识、字段校验、提交状态和防重复机制。

模型自主决定是否参考历史、如何处理多笔交易以及何时结束；程序负责限制允许执行的操作，并根据实际工具回执生成结果。业务流程不固定为「抽取、分类、查询、写入」的一条流水线。

## 自用时的行为

- 处理已经发生的人民币支出，一条消息可以包含多笔消费。
- 根据明确用途、消费对象、个人分类规则及其边界判断完整分类；无法唯一确定的消费不强行入账。
- 金额、日期、消费详情和计算依据必须能够追溯到原消息；问题消费单独说明，其他合法消费继续处理。
- 只允许在固定账本查询有限历史样本、逐笔新增消费，不支持修改或删除已有记录。
- 只有确认写入成功才反馈已记账；明确失败与结果不确定分别反馈，待核对记录不自动重试。

## 唤醒与会话

只有两种方式可以开启记账：

1. 直接发出准确指令「记账小助手帮我记账」，可以同时附带消费内容。
2. 明确要求使用 `feishu-bookkeeping` Skill 记账。

开启后，当前会话可以直接发送后续消费，明确停止记账后关闭。其他聊天和其他宿主的会话需要单独唤醒。普通消费描述、相似口令、引用、否定、附件内容，以及本 Skill 的开发、安装或审阅请求都不构成唤醒。

## 实现结构

```text
宿主智能体（模型与 Harness）
          │
          ▼
      Skill 指引与个人知识
          │
          ▼
      受限 Python 执行器
          │
          ├── 会话门禁、金额日期分类校验、SQLite 提交日志
          │
          └── 固定参数的 lark-cli → 固定飞书账本
```

执行器只提供两个业务操作：

| 操作 | 边界 |
|---|---|
| `query_history` | 仅查询固定账本的有限分类样本，最多 50 条，仅按消费详情关键词筛选 |
| `add_expenses` | 最多接收 100 笔，逐笔校验、串行提交，只写入六个固定消费字段 |

会话、任务、知识和结果入口只管理执行状态，不扩大账本权限。模型不能通过参数指定其他表、额外字段、任意命令、更新或删除操作。提交前持久预留原文范围，重叠范围不重复提交；中断后无法确认的提交保留为待核对。

这是普通 Skill 配合受限执行器的实现，不会关闭宿主本身的其他工具。Skill 要求所有账本操作经过执行器，工具层负责校验与限制。

## 仓库内容

| 目录或文件 | 内容 |
|---|---|
| `feishu-bookkeeping/SKILL.md` | 宿主读取的记账指引与触发条件 |
| `feishu-bookkeeping/scripts/` | 受限执行器、状态管理与本地安装器 |
| `feishu-bookkeeping/references/` | 业务规则、工具协议和作者自用环境说明 |
| `tests/` | 人工合成数据测试、隔离账本替身与验收核对工具 |
| `scripts/package_skill.py` | 作者在本地生成私有分发包的工具 |
| `docs/` | 验证结果与实现记录摘要 |

`private/` 中的个人分类知识和真实账本配置不属于仓库内容。私有安装包、实际消费明细、验收原始日志、执行数据库、虚拟环境和缓存仅保留在本地。仓库中的安装器和打包脚本用于记录自用实现，不意味着仓库提供了完整可运行的个人环境。

## 验证记录

开发时通过了 15 项确定性测试，并使用不继承开发对话、没有预期答案的新智能体完成最终版本验收。21 条消息产生并完成 10 个任务、20 笔本地模拟提交；未唤醒消息、跨会话消息及跨宿主消息没有触发业务操作。

验收使用本地账本替身，移除生产 CLI 适配器，并禁止外部进程和网络连接。验收期间没有写入真实多维表格。安装后的真实检查仅读取账本字段结构。具体记录见 [验收与安装报告](docs/acceptance-report.md)。

公开的合成数据测试不需要个人知识库或飞书授权。准备 Python 3.11 或以上及依赖后，可运行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r feishu-bookkeeping/requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

本地脚本与标准 Skill 结构可以供其他支持文件读取和脚本执行的宿主使用；这不等于已在所有客户端验证。本项目未在豆包客户端内进行实装验收。
