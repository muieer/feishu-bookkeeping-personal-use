## 隔离方式

验收副本移除生产 CLI 适配器，替换目标标识与表结构，仅注入本地账本；入口增加审计钩子，禁止外部进程和网络连接。验收不加载真实认证资料，不以真实新增命令的 dry-run 作为隔离保障。真实账本字段检查在验收和安装完成之后单独进行，实际 CLI action 只有 schema。

最终验收的实际回执与核对结果保存在私有的 `acceptance/final/`。该目录及其中个人测试资料已被 Git 忽略。可提交的机器可读摘要为本目录的 `acceptance-results.json`，不包含账本标识或消费明细。
